# 2026-10-05

## ตาราง users

- ตาราง `users` ใช้ id ของ Supabase Auth
- sync ตอนเข้าแดชบอร์ดและตอนเรียก API
- แอดมินจัดการบทบาทและสถานะที่ `/users`
- `ADMIN_EMAILS` ยังเป็นแอดมินถาวร ปิดบัญชีตัวเองไม่ได้
- `users.member_id` ชี้สมาชิกได้หนึ่งคน ลบสมาชิกแล้วค่ายว่าง
- แอดมินเพิ่มผู้ใช้และกำหนดบทบาทได้ที่ `/users` บัญชีใน ADMIN_EMAILS ยังเป็นแอดมินถาวร

## จัดทีม (schema)

- เพิ่ม enum `TeamSlotType`, `TeamSessionStatus` และโมเดล `Team`, `TeamSession`, `TeamAssignment`
- `Player.teamAssignments` เป็น one-to-many เก็บประวัติหลายรอบ
- migration `20261005140000_add_team_management` สร้างตารางใหม่เท่านั้น
- ใส่ทีม 1–3 แบบไม่ซ้ำ ยังไม่มี API/UI

## หน้าจัดทีม

- `/teams` สำหรับแอดมิน ลากหรือกดย้ายผู้เล่นระหว่างรอเล่น ทีมหลัก สำรอง และไม่เล่นแล้ว
- หลักเต็ม 5 สำรองเต็ม 3 จบรอบแล้วประวัติรอบเก่ายังอยู่และเปิดรอบร่างใหม่
- กดแก้ไขบนการ์ดทีมเพื่อเปลี่ยนชื่อและจำนวนคนหลัก/สำรองของทีมนั้น ลดจำนวนต่ำกว่าผู้เล่นที่อยู่ในช่องไม่ได้
- ลากปุ่ม ⠿ บนกล่องทีมเพื่อสลับตำแหน่ง กล่องสำรองของทีมนั้นขยับตาม
- รีสตาร์ตเซิร์ฟเวอร์หลังเพิ่มฟิลด์จำนวนคน เพราะโปรเซสเดิมยังใช้ Prisma client ตัวเก่า
